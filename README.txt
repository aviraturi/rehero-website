REHERO — Recruitment Services Website

Files:
- index.html — homepage
- styles.css — design/styles
- script.js — interactions

Deployment:
Upload these files to the root of your GitHub repository, or set the Vercel Root Directory to the folder containing index.html.

Brand focus:
REHERO is presented here as a recruitment-services business only. HR and operations service messaging has been removed from the website content.

Before launch, replace placeholder email/WhatsApp details in index.html with REHERO's real contact details.
